# Halloween Minigames

Cinco minijogos de consola em C# desenvolvidos para o evento de Halloween
da Escola Profissional de Tecnologia Digital, por alunos do 2.º ano de
Técnico/a de Gestão e Programação de Sistemas Informáticos.


## Como correr

Requisitos: .NET [4.7.2]

    cd HalloweenTiming
    dotnet run

## Notas

Desenvolvido com os conhecimentos de C# adquiridos no curso. Foi usada
IA para automatizar tarefas repetitivas, como gerar blocos de código
semelhantes. O conhecimento adquirido foi 2 meses de aulas.
